# Git Version-Controlled DevOps Project

## DevOps Internship - Task 4

This project demonstrates Git and GitHub version-control best practices.

## Objective

To manage a DevOps project using Git with proper branching, commits, pull requests, tags, and documentation.

## Tools Used

- Git
- GitHub

## Branching Strategy

- `main` - stable version
- `dev` - development branch
- `feature` - feature development branch

## Git Workflow

Feature development
        ↓
Feature branch
        ↓
Pull Request
        ↓
dev branch
        ↓
Pull Request
        ↓
main branch
